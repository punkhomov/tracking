# Функции Tracking

| Область | Поведение |
| --- | --- |
| Таймер | Работа и перерыв, старт, пауза, продолжение и сохранение. Короткая пауза учитывается как активное время. Длительность, порог паузы, повтор напоминаний и автостарт настраиваются. |
| Сессии | Заметки и категории, просмотр истории, ручное добавление, редактирование, удаление и поиск. Архивирование категорий сохраняет ссылки из истории. |
| Таймлайн | Фактические сессии и плановые зоны дня. У зоны есть дни недели, ожидаемая категория, даты действия, отдельные даты-исключения и вложенные зоны. |
| Статистика | День, неделя и месяц, распределение активности, тепловая карта и метрики соответствия зонам. Активное время считается за вычетом засчитанных пауз. |
| Настройки | Светлая, тёмная и системная тема, первый день недели, форматы даты и времени. |
| Архив | Импорт настроек, истории или полного JSON v1, экспорт и восстановление формата v2. Есть добавление без дублей и замена истории. |
| Улучшения | Сохранение активного таймера при перезапуске, поиск и фильтры истории, опциональный Supabase. |

Основные сценарии работают локально. После подключения своего проекта Supabase история, категории, зоны и настройки синхронизируются между устройствами по кнопке. При конфликтующих правках пользователь выбирает версию. Активная сессия хранится на устройстве, где запущена. [Настройка Supabase](supabase.md)

Новая зона по умолчанию действует с сегодняшнего дня. Дата окончания включительна. Чтобы закончить прежний рабочий график, укажите последний день и создайте отдельную зону для нового графика. В даты-исключения зона и её вложенные зоны исчезают из плана и расчёта соответствия плану. Фактические сессии продолжают учитываться в истории и общей статистике.

Android запланирован после desktop и web. Он использует общую логику таймера, истории и отчётов из `tracking-core`.
